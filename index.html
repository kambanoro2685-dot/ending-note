はじめに

「わたしの人生すごろく」（以下「本アプリ」）は、エンディングノートを書き残すための無料のウェブアプリです。ノートには、病歴、資産、家族のこと、葬儀の希望など、とても私的な情報が含まれます。以下を最後までお読みのうえ、同意される場合のみご利用ください。

第1部　プライバシーポリシー

1. 運営者はあなたの情報を一切受け取りません

本アプリに入力した内容は、お使いのパソコン（またはスマートフォン）のブラウザ内にだけ保存されます。運営者のサーバー、クラウド、Googleアカウントなど、この端末以外のどこにも送信・保存されません。本アプリには、外部への通信を技術的に禁止する設定を入れています。運営者も、あなたのノートを見ることも、復元することもできません。

2. 取得しない情報

  • アカウント登録・ログインはありません。氏名・メールアドレス等を求めません。
  • Cookie、アクセス解析、広告、外部のフォントや部品の読み込みは使っていません。

3. ページの配信について

本アプリは GitHub Pages（GitHub, Inc.）で配信されています。ページを開く際、GitHub が通常のウェブ配信に伴うアクセス記録（IPアドレス等）を扱う場合があります。これはノートの内容とは無関係で、運営者はその記録を取得・利用しません。詳しくは GitHub のプライバシーに関する声明をご覧ください。

4. 保存される場所と内容

  • ノート本文：ブラウザの保存領域（localStorage）に保存されます。パスワードを設定したマスは、ブラウザ内で暗号化（AES-GCM）された状態で保存されます。パスワードを設定していないマスは、暗号化されません。
  • 「この端末では次回から自動で開く」を選んだパスワード：暗号化されずにこの端末のブラウザ内に保存されます。家族や他の人が使うパソコン、共用パソコンでは選ばないでください。
  • 同意の記録：この規約に同意した事実と版を、ブラウザ内に保存します。

5. あなたが作るファイルと印刷物

「保存(JSON)」で書き出したファイルや印刷物は、あなた自身の管理物です。パスワードを設定していないマスの内容は、そのファイルの中に読める形で含まれます。保管・受け渡し・廃棄は、あなたの責任で慎重に行ってください。ファイルをメール・クラウド等に置いた時点で、この端末以外に保存されることになります。

6. 第三者への提供・目的外利用

運営者は情報を受け取らないため、第三者に提供することも、利用することもありません。

7. 削除の方法

画面上部の「すべて消去」ボタン、またはブラウザの「サイトデータの削除」で、この端末のノートとパスワードを消せます。消去したものは元に戻せません。

8. 他人の個人情報について

ノートに家族・友人など他の方の氏名や連絡先を書く場合は、その方への配慮をお願いします。
